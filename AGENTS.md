# Regras do projeto

- Desenvolva mobile-first; tablet é prioritário e desktop continua suportado.
- A interface é moderna e editorial; ilustrações são conteúdo, não substitutos da interface.
- Prefira componentes reutilizáveis e dados desacoplados da apresentação.
- Identifique conteúdo demonstrativo para que não seja confundido com dados reais.
- Preserve funcionalidades existentes ao adicionar novas capacidades.
- Responsividade e acessibilidade são obrigatórias, incluindo foco visível e semântica.
- Não faça deploy ou commits automaticamente.
- Não implemente recursos fora do escopo sem necessidade clara.
